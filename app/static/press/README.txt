Press releases PDFs go in this folder.

Naming convention: vol-YYYY-XXX.pdf

For the first release (vol-2026-001), the Download PDF button currently guides visitors to the "Print / Save as PDF" flow inside the article modal until the official PDF file is placed here.

To add a real PDF later:
1. Generate or obtain the PDF
2. Place it here as vol-2026-001.pdf (or update the pdf_url in press_releases.py)
3. The download link will serve it directly.

No code changes required for additional releases.
